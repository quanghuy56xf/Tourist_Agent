Kiến trúc Hệ thống (Architecture)

Mô hình Self-hosted & Multi-tenant

  • Frontend: Next.js 14, React 18
  • Backend: FastAPI, Python
  • Vision: DINOv2 + ChromaDB
  • RAG: Hybrid (Bi-encoder + BM25)
  • LLM: Generative AI (Gemini)
  • TTS: Edge TTS (Streaming)
  • Database: SQLite (Metadata)
  • Infrastructure: Docker, Cloudflare

Roadmap Tương lai

  • Multi-language: Triển khai giao diện và giọng đọc i18n đầy đủ.
  • Multi-site Heritage: Quản lý tập trung nhiều di tích (Group) riêng biệt.
  • AR Features: Ứng dụng thực tế tăng cường trên hiện vật thực tế.
  • Offline Mode: Cache nội dung để sử dụng khi kết nối mạng kém.
  • Analytics Dashboard: Phân tích chi tiết Insight và Journey của khách tham quan.
